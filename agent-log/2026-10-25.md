# Agent log — 2026-10-25

## Summary
**Bug:** after choosing "I'm designing my home" on the choose-path screen, the app hung on a blank page.
**Cause:** that button opened /start with a "came from choose path" flag. /start sends home owners on to /journey, but in the same moment it rewrote the address back to /start to clear the flag. That cancelled the redirect, and the page stayed blank until a reload.
**Fix:** the button now goes straight to /journey. /start also no longer rewrites the address when it's about to redirect, so old links and bookmarks work too.
**Measured** (Playwright, Supabase mocked at 300 ms per request): before, the page never reached the journey (blank after 60 s). After, the journey shows in 0.14–0.8 s, including on a throttled connection.
**Tests:** 29/29 pass (3 new; the regression test fails on the old code). Build and type check pass. Lint is unchanged at 196 errors, all from before this fix.
